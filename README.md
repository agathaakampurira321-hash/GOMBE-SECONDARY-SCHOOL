# Gombe Secondary School Website

Static HTML5 and CSS website for the ICT 1105 final project.

## Pages

- `index.html` - Home
- `about.html` - About
- `services.html` - Academics
- `gallery.html` - Gallery
- `media.html` - Media
- `contact.html` - Contact
- `faq.html` - FAQ
- `Form.html` - Admission form

## Asset Sources and Licence

The school photograph and media files in `videos and images/` were provided for this project. The website code was hand-written in HTML5 and CSS.
